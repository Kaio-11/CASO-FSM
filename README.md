# Caso FSM — Enfermagem Clínica e Cirúrgica

Página interativa de estudo do caso clínico FSM.

## Publicar no GitHub Pages

1. Abra o repositório `CASO-FSM` no GitHub.
2. Na aba **Code**, clique em **Add file → Upload files**.
3. Extraia este pacote no computador e envie os arquivos `index.html` e `README.md` para a raiz do repositório.
4. Clique em **Commit changes**.
5. Abra **Settings → Pages**.
6. Em **Build and deployment**, selecione **Deploy from a branch**.
7. Selecione `main` e a pasta `/(root)`; clique em **Save**.
8. Aguarde o deploy em **Actions** e abra https://kaio-11.github.io/CASO-FSM/.

**Importante:** o nome deve ser exatamente `index.html`, em letras minúsculas, sem espaços ou números entre parênteses. Ele deve ficar na raiz da pasta publicada.

## Sobre os dados
As avaliações e anotações são armazenadas no navegador utilizado. Elas não são enviadas ao GitHub nem sincronizadas entre aparelhos.
